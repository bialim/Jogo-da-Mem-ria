# Jogo da Memória
Jogo progamado para Arduino Uno. 
<br> 
<div align="left">
<h3>Materiaiss</h3>
Arduino Uno, jumpers, 5 Leds, 5 Botões, Buzzer.
<br> 
<div align="left">
<h3>Funcionalidades</h3>
O jogo pode ser jogado com uma ou duas pessoas. A quantidade de pessoas deve ser informada no teminal, assim como as mensagens de vitória, derrota e pontuação também são disponipilizadas no terminal. Caso o jogo seja com duas pessoas, seus nomes devem ser informados para que joguem um de cada vez. 
<div align="left">
<h3>Regras</h3>
O jogor precisa memorizar a sequência de cores mostradas nos leds. O jogador tem quantas tentativas quiser para acertar a sequência, porém, a cada tentativa errada a sequência de leds é redefinida. Para auxiliar os jogadores e deixar mais interativo a cada led aceso um som é emitido, assim como quando uma sequência é certa ou errada também tem uma melodia para cada situação. Além disso, ao vencer o jogo o seu tempo de jogo é disponibilizado.

<div align="left">
<h3>Objetivo</h3>
Estudar e implementar conseitos do TIMER1, o qual é um timer utilizado para temporização, contagem de eventos externos, interrupções periódicas, etc. Neste projeto ele foi utilizado para controlar o som do buzzer, que alerta o jogador quando ele vence.
